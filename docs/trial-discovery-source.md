# 体験予約：クラブを知ったきっかけ

共通の `/reserve` フォームで「チラシ」「紹介」「その他」をこの順に表示し、選択を必須にする。「紹介」の場合だけ任意の紹介者名を表示する。他の選択肢では、非表示の紹介者名を送信・下書き保存しない。LINE控えにも選択内容を記載する。

`discoverySource` はWorkerで選択肢を検証し、予約OutboxからGASへ転送する。先にGAS側の対応版を同じdeployment IDへ配備し、その後Workerを公開する。GASは中央受付 `14_LINE体験受付` のK列（原文）・AI列（エラー・備考）へ保存する。紹介者名は従来のT列を使い、名前が空欄の紹介を架空の紹介者名で補完しない。

旧フォームの再送は引き続き受け付ける。きっかけが未送信の場合は既存のOutbox・GAS receipt cacheのfingerprintを変えず、既存予約の再送と旧下書きの紹介者名を保持する。旧下書きに紹介者名があれば「紹介」として復元する。

検証：`npm test` と `npm run check`。本番へテスト予約やLINEメッセージを送らず、公開HTMLとhealth endpointを確認する。
