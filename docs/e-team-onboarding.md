# Eチーム・鶴ヶ島藤の追加

月曜、前半17:00〜17:50／後半18:00〜18:50。予約ルートは `e/tsurugashima-fuji`。
クラス状態と表示時刻の正本は既存の中央受付設定。新規登録時は2クラスとも受付停止。

## 配備順

1. 本Workerを配備。既存GASの30会場pushも引き続き受理し、不足するEだけを「空日程・2クラス受付停止」に補完する。A〜Dの欠落・未知ルート・不正なE設定は従来どおり拒否する。
2. `prospect-gas/apps/line-intake-gateway` のE対応を別途承認・配備する。既存Webアプリのdeployment IDを維持して新バージョンへ更新し、`syncProspectTrialConfig` で31会場を同期する。
3. Cloudflareに `LINE_SECRET_E_TSURUGASHIMA_FUJI` を登録し、鶴ヶ島藤のMessaging APIに会場別Webhook URLを設定・検証する。秘密値をソース・PR・ログへ記録しない。
4. `prospect-gas` のE運用入力同期を別途承認・配備し、Eファイルの編集トリガーを追加する。既存A〜Dのトリガーは保持する。
5. Eの設定取得・表示・保存・管理シート反映・LINE控えを実機で確認してから、両クラスを通常受付にする。実データへのテスト申込は管理者が明示した内容で行う。

GASを旧版へ戻した後の30会場pushはEを再び閉じるため、古いEの受付可能状態を残さない。
この変更に資格情報の登録、GAS配備、トリガー作成、LINE設定変更の実行は含めない。
